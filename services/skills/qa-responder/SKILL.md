# qa-responder

## 职责

回答久坐、颈肩腰背劳损相关的行为与执行类问题，回答必须基于知识库条目，附引用与免责声明，并在涉及医疗判断时引导就医。

## 输入

```json
{
  "user_id": "uuid",
  "question": "开会太久，怎么在工位上缓解颈肩紧张？",
  "state": "S1",
  "body_parts": ["neck", "shoulder"]
}
```

## 输出

```json
{
  "answer": "可以在座位上做 30 秒颈部放松……",
  "citations": ["knowledge:sitting-break-101"],
  "state_hint": "S1",
  "disclaimer": "本产品为健康行为指导工具，不提供医疗诊断或治疗建议。",
  "escalated_to_medical": false
}
```

## 边界

- 不诊断、不解释影像报告、不评估用药、不给康复周期承诺。
- 命中 `safety-check` 红旗时，本 Skill 不参与生成，直接返回就医提示。
- 不读写数据库；问答日志由云端统一写 `qa_logs`。
- 回答长度 ≤ 150 字，先给可直接执行的动作，再给一句原理。
- 知识库检索不到时明确说"资料中没有"，不编造。

## 示例

> 问：久坐后腰酸，要不要躺着休息？
> 答：不建议长时间躺卧。先起身走动 2 分钟，再做 3 组坐姿骨盆前后倾，每组 10 次；若疼痛持续加重请就医。
