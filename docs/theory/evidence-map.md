# 证据映射（模块 / BCT / 主题 ↔ 文献）

## 文档信息

| 项 | 内容 |
|---|---|
| 用途 | 把 PRD 的可配置参数与行为改变路径，逐条挂到可核验文献上；答辩时用于说明“参数不是拍脑袋” |
| 状态 | **骨架**：Phase 0–5 只登记映射关系；文献 id 在 Phase 6 由 curator 回填 |
| 上游 | `PRD.md` 第 4、5、10 节；`docs/theory/agent-workflow.md` |
| 下游 | `data/knowledge/evidence.json`、`data/knowledge/qc-report.md` |
| 边界 | 离线资料文档，不参与产品运行时，不接入 `services/agent-orchestrator` |

> 填表规则：`evidence.json` 里的 `applies_to` 与 `topics` 决定本表回填位置。一个参数可以对应多条文献，
> 但每条文献至少要有一个主题；没有文献支撑的参数必须在这里显式标 `待补`，不许留空装成已支撑。

## 1. 系统参数 ↔ 证据锚点

| 参数 | 当前取值 | 依据主题 | 文献 id（Phase 6 回填） | 说明 |
|---|---|---|---|---|
| 久坐阈值 | 45 分钟（可配 30–60） | `sedentary-threshold` | 待补 | WHO 建议每 30–60 分钟打断久坐；需一条指南 + 一条综述同时支撑上下界 |
| 单次干预时长 | 2–10 分钟（S0 ≤2 / S1 3–5 / S2 5–8 / S3 2–5） | `micro-break-workplace`、`neck-shoulder`、`low-back` | 待补 | 证据窗口由“微休息有效剂量”类研究支撑 |
| 推送去重窗口 | 同一用户 10 分钟内不重复推送 | `sedentary-threshold`、`bct` | 待补 | 需支撑“打断过密反而降低依从性”，否则该常量应删 |
| S0 进入条件 | 疼痛 ≤3 分且无红肿热痛 | `safety-redflag` | 待补 | 急性期只做静态拉伸的边界 |
| S0 退出条件 | 完成 2–3 次、评分 ≤3、次日无加重 | `neck-shoulder`、`low-back` | 待补 | “练完不加重、次日不更痛”的判定出处 |
| 升级门槛 | S1 ≥5 次、S2 ≥10 次连续完成 | `bct` | 待补 | 目标设定与习惯形成的次数依据 |
| 回退规则 | 连续 2 次症状加重回退一级 | `safety-redflag`、`bct` | 待补 | 与“症状恶化即降负荷”的康复原则对齐 |
| 降级规则 | 连续跳过 / “没感觉”且无加重，不降状态、换更短动作 | `bct` | 待补 | 与障碍归因（太忙/太难/没地方/忘了）联动 |
| 安全短路症状 | 放射痛、麻木加重、眩晕、下肢无力、踩棉花感、大小便异常、会阴麻木、外伤后剧痛 | `safety-redflag` | 待补 | 8 条红线必须逐条有出处，缺一条即视为未支撑 |
| 障碍归因选项 | 太忙 / 动作太难 / 没地方做 / 忘了 | `bct` | 待补 | 对应“问题解决”技术，需 BCT 分类学条目 |
| 周度回顾指标 | 完成率、状态轨迹、平均久坐间隔、高频跳过时段 | `bct` | 待补 | 对应“自我监测与反馈” |
| 两周微目标 | “两周内稳定执行 S1” | `bct` | 待补 | 对应“目标设定与监测” |
| if-then 计划 | Onboarding 选“立刻做 / 5 分钟后提醒” | `bct` | 待补 | 对应“行动计划” |

## 4. 与产品边界的关系

- 本表只解释“为什么这么设”，不替代医疗声明。PRD 第 10 节固定措辞与 `safety-check` 中间件不因本表改变。
- `safety-redflag` 主题的文献只能用于**识别与转诊边界**，不得被引用为“产品可做诊断”的依据。
- 任何一条文献都不得让系统越过 `safety-check` 中间件，也不得让端侧获得状态迁移能力。
