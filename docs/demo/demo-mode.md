# 本地模式（纯端侧，数据不出本机）

## 入口

桌面端登录页底部「或者进入 / 本地模式」。

点击后客户端切换到 `packages/local-engine`，不发起任何网络请求，自动使用本地演示账号进入首次评估；若本地已有评估记录，则直接恢复到上次的主界面。界面顶部显示「本地模式」徽标。

## 实现

| 组成 | 位置 | 说明 |
|---|---|---|
| 状态机 | `packages/local-engine/src/machine.js` | 与 `packages/intervention-engine` 同一套迁移规则（upgrade / rollback / degrade / short_circuit） |
| 动作库 | `data/actions/actions.json` | 唯一数据源，构建时只读导入，端侧不另写副本 |
| 安全前置 | `packages/local-engine/src/safety.js` | 红旗关键词与字段双路检测，命中即中断并提示就医 |
| 持久化 | 浏览器 `localStorage` | 键 `riseloop.local.v1`（评估、会话、迁移、执行记录）与 `riseloop.local.logs.v1`（会话记录） |
| 适配层 | `apps/desktop-tauri/src/state/local.js` | 把本地引擎包装成与 `api-client` 相同的方法签名 |

无需启动 `cloud-api`、RDS、Redis 或任何本机进程。

## 本地模式下可用

- 首次评估与初始状态判定（S0/S1）
- 久坐计时、阈值调整、暂停/继续（Tauri 内由 Rust 计时；浏览器预览由前端兜底计时）
- 动作库推送与执行指引
- 反馈提交与四分支状态迁移
- 安全红线短路与就医提示
- 本地周复盘：近 7 天完成率、疼痛趋势、阻碍分布与规则化建议（纯本地统计，不调用智能体）
- 会话记录、迁移历史、执行记录（localStorage 持久化，重启后保留）

## 本地模式下不可用

| 能力 | 原因 |
|---|---|
| 智能问答 | 依赖 CodeArts 智能体与知识库 |
| AI 洞察增强 | 依赖 CodeArts 双 Agent 编排 |
| 云端周度聚合 | 需要云端事实数据；本地周复盘只统计本机记录 |
| 跨设备同步 | 无云端账号体系 |

界面会在进入本地模式时把上述限制写入会话记录，并在洞察面板提示「智能问答不可用」。

## 数据边界

- 存储：浏览器 `localStorage`，位于应用数据目录。
- 生命周期：持久保留，直到用户清除浏览器数据或调用本地引擎 `reset()`。
- 清除：顶栏个人菜单 →「清除数据」，二次确认后同时删除 `riseloop.local.v1`、`riseloop.local.logs.v1`、登录令牌与内存状态，并回到登录页。
- 不上传：本地模式不连接任何华为云资源。
- 切换：退出本地模式会回到云端登录页，本地数据保留；再次进入可继续上次评估。

## 与架构红线的关系

- 端侧只允许 `packages/local-engine` 承载离线演示用的状态机，云端模式仍必须走 `cloud-api` + `intervention-engine`。
- 动作库不硬编码，直接引用 `data/actions/actions.json`。
- 两套实现必须保持同一迁移规则；修改任一侧需同步另一侧并补测试（`packages/local-engine/test`、`packages/intervention-engine/tests`）。
- 本地模式与云端模式互不自动切换，正式评审不得以本地模式替代云端公网链路验证。

## 排查

| 现象 | 含义 | 处理 |
|---|---|---|
| 点击后停在登录页并提示错误 | 本地引擎初始化失败 | 检查浏览器是否禁用 `localStorage` |
| 数据没有保留 | 隐私模式或站点数据被清理 | 关闭隐私窗口或使用 Tauri 客户端 |
| 浏览器预览下计时不动 | 预览环境无 Tauri 计时 | 使用 `pnpm tauri dev`，或点击「演示：快进到阈值」 |
| 清除数据后仍看到历史 | 当前处于云端模式，数据在服务端 | 清除数据只清本机；云端历史需在云端侧管理 |

## 现场保底

1. 提前用 `pnpm tauri dev` 跑通一次，确认客户端与本地引擎加载正常。
2. 会场网络不可用时，本地模式仍可完整展示本地闭环，且重启后数据仍在。
3. 需要展示华为云能力时，用云端模式 + 录屏，本地模式不替代上云验收。
